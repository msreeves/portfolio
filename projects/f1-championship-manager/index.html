F1 Championship Manager

A local championship dashboard for Sony PAL Formula One 2001–2006 in PCSX2 — stage results, preview points, and approve only when you are happy with the classification.

Try it: open the dashboard on your machine (port 8787) when the tool is running — npm run f1cm:launch from the workspace, or login autostart after install.

Open dashboard Back to selected work

Where the idea came from

I play the classic Studio Liverpool PAL titles in PCSX2 and watch races in the game's TV spectator mode instead of driving every lap. That mode is great for watching a Grand Prix unfold — but I still wanted a real championship: calendars, grids, points, and standings that carry from round to round.

The tool grew from that gap: spectator mode supplies the entertainment; the dashboard supplies the season — pick the year and event, note who finished where after you have watched the race, preview the points impact, then approve so only committed results change the table.

What it does

  • Python FastAPI UI on http://127.0.0.1:8787/ with SQLite for approved championship data.
  • 2001–2006 seasons — official vs reversed grids, staging workflow, and backups before approved writes.
  • Optional PCSX2 / PINE hooks for identity checks; race classification stays manual lock-in on purpose.
