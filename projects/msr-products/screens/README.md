# MSR Products — site screen exports

JPEGs here are **captured from the live local shop** (not Figma).

```bash
npm run msrproducts:design-screens:capture
```

Requires Herd + Playwright browsers (`cd localhost/web-dev-tools/preview && npx playwright install chromium` once).

Outputs: `home-1440.jpg`, `shop-1440.jpg`, `product-1440.jpg`, `contact-1440.jpg`.
